# ML Evaluation

## Scope

This report is based entirely on synthetic PCAP fixtures generated by
`tools/make_synthetic_pcaps.py`. The numbers below are not evidence of field
accuracy, generalization, or production readiness. They only describe this
synthetic dataset and this exact seeded model.

## Design

- One shared IsolationForest over BSSID-scope windows.
- RobustScaler preprocessing with median imputation for NaN and infinite values.
- 200 trees, contamination 0.05, seed 42.
- Training uses only the first 70 percent of benign window time.
- Evaluation uses the last 30 percent of benign window time and the mixed attack
  captures.
- Operational window score is the maximum score across BSSID rows sharing the
  timestamp window.
- Scoring is `1 / (1 + exp(raw_decision_function * 8))`. A lower raw value is more
  anomalous, so higher normalized values are more anomalous.

Held-out benign false positive rate at the 95th percentile: 0.0543.

## Limits

- Deauth and KARMA ranking are weak. Their mean scores are higher inside the
  labeled interval, but ROC-AUC and PR-AUC show limited window-level separation.
- The attack intervals are short relative to a 12-minute mixed capture, producing
  very few positive windows in the ranking metrics.
- Only 129 held-out benign windows are available. FPR estimates are unstable.
- RSSI, channel, and timing values are synthetic and may not match field capture.
- The ML score is one ensemble input. Rules provide the primary evidence and the
  model never supplies a standalone verdict.
