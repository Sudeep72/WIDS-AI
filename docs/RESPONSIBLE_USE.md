# Responsible Use

WIDS-AI is for authorized defensive monitoring only. Use it on your own network
or a network for which you have documented written permission. Wireless capture
can reveal device identifiers, network names, and client behavior, and local law
may restrict interception or storage of communications.

The project contains no transmit, injection, deauthentication, or attack code.
Do not add such code to detection tests or tools. Validate only against isolated
equipment you own or are explicitly authorized to test. Do not use the project
to disrupt, impersonate, or surveil third parties.

Keep captures, inventories, databases, and exported SIEM events in an access
controlled location. Review applicable privacy, retention, and monitoring laws
before deployment.
